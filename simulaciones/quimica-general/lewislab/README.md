# LewisLab

Simulador interactivo para GitHub Pages sobre símbolos y estructuras de Lewis.

## Incluye
- símbolos de Lewis de átomos;
- conteo de electrones de valencia;
- construcción guiada de moléculas orgánicas e inorgánicas;
- carga formal y resonancia;
- constructor de órdenes de enlace;
- excepciones: octeto incompleto, electrones impares e hipervalencia;
- mini-desafíos.

## Nota científica
Las estructuras de Lewis son modelos de contabilidad electrónica. En especies hipervalentes, una explicación moderna del enlace no requiere asumir una expansión simple del octeto por hibridación con orbitales d.

# AtomLab — Del experimento al modelo atómico

Simulador histórico-conceptual para GitHub Pages.

## Módulos
- línea temporal interactiva;
- Dalton, Thomson, Rutherford, Bohr y modelo cuántico;
- de Broglie, Schrödinger, Heisenberg, Davisson–Germer y Chadwick;
- simulaciones didácticas de rayos catódicos, dispersión de Rutherford, espectro de H y difracción electrónica;
- comparación de modelos;
- desafíos de predicción.

## Enfoque
Se diferencia entre modelo, teoría, experimento y descubrimiento. Las simulaciones son representaciones didácticas cualitativas, no reproducciones numéricas de los montajes originales.

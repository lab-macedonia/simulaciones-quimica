# GeoMol — VSEPR, geometría y polaridad

Simulador interactivo 3D (proyección en Canvas, sin dependencias externas) para GitHub Pages.

## Incluye
- AX2 a AX6 con pares libres relevantes;
- geometría electrónica y molecular;
- ángulos ideales/aproximados;
- rotación 3D con mouse o dedo;
- pares libres;
- vectores de dipolo;
- polaridad molecular;
- ejemplos: CO2, BF3, SO2, CH4, NH3, H2O, PCl5, SF4, ClF3, XeF2, SF6, BrF5 y XeF4;
- constructor AXnEm;
- comparación y desafíos.

## Nota
Las etiquetas sp3d y sp3d2 se muestran como nomenclatura VSEPR/hibridación tradicional de cursos introductorios, no como una afirmación de que la descripción moderna de hipervalencia requiera orbitales d híbridos.

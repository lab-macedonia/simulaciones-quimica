Learning objectives

By the end, the student will be able to:

  • Use Q and K to predict the direction of the reaction.
  • Apply Le Châtelier's principle.
  • Solve equilibria with an ICE table.

Suggested activity

Disturb the equilibrium

  1. With N₂ + 3H₂ ⇌ 2NH₃ note the initial state.
  2. Apply each disturbance and predict the direction.
  3. Check it in the simulation.
  4. Explain why the catalyst does not alter K.

Common mistakes

MisconceptionCorrection
“A catalyst shifts the equilibrium.”It speeds up both directions; it does not change K.
“Adding an inert gas always shifts it.”At constant V it does not change the partial pressures.
“K changes with concentration.”Only with temperature.

B. Essay

1. At 500 K, K = 0.25 for A ⇌ 2B. If [A]₀ = 1.0 M and [B]₀ = 0, calculate the equilibrium concentrations.

2. Explain the van 't Hoff equation qualitatively.

Answer key

Multiple choice

  1. B. products — Until Q = K.
  2. B. decreases K — It favors reactants.
  3. B. favors NH₃ — Fewer moles of gas.

Essay (marking guide)

  1. K = (2x)²/(1 − x) = 0,25 → 4x² + 0,25x − 0,25 = 0 → x ≈ 0,22; [B] = 0,44 M, [A] = 0,78 M.
  2. If ΔH > 0, K rises with T; if ΔH < 0, K falls.

Common mistakes

MisconceptionCorrection
“The electron orbits like a planet.”The Bohr model is an approximation; orbitals are used today.
“Emission occurs when going up a level.”Going up absorbs; going down emits.
“All series are in the visible.”Only Balmer; Lyman is UV, Paschen IR.

B. Essay

1. Calculate λ for n = 4 → 2.

2. Explain the de Broglie condition 2πr = nλ.

Answer key

Multiple choice

  1. C. −13,6 eV / n² — Eₙ = −13.6 eV·Z²/n²: negative and tending to 0 as n → ∞.
  2. B. emits a red photon (Hα, 656 nm) — ΔE = 1.89 eV → λ = 656 nm; on dropping a level, a photon is emitted.
  3. A. n = 1 (ultraviolet) — Lyman: n → 1, UV region.
  4. D. 13.6 eV — It is |E₁| = 13.6 eV, equivalent to λ ≤ 91.2 nm.
  5. C. −54.4 eV — E₁ = −13.6·Z² = −54.4 eV.
  6. B. 2πr = nλ — The circumference must contain a whole number of wavelengths.
  7. A. n² — rₙ = a₀n²/Z.
  8. D. one-electron systems — It works for H, He⁺, Li²⁺; it does not explain many-electron atoms.
  9. B. visible (red) — 656 nm (H-α).
  10. C. −54.4 eV — −13,6 × Z² = −54,4 eV.
  11. C. 211,6 pm — a₀·n² = 4 × 52,9.

Essay (marking guide)

  1. 1/λ = R(1/4 − 1/16) = 1,097×10⁷ × 0,1875 → λ = 486 nm.
  2. Only orbits that fit a whole number of electron wavelengths are stable: quantization.
